jsoo-code-mirror examples

Each page is one .ml file in examples/, built against the smallest set of libraries it needs. Serve this directory from _build/default/examples.

ocaml
An OCaml editor: the legacy mode, One Dark, and the standard setup. What embedding one actually looks like.
language
A stream parser written by hand, a highlight style over its tags, and walking the syntax tree.
commands
The default key bindings, history, undo and redo, indentation and commenting.
autocomplete
Completion from a list and from a source of our own, bracket closing, a snippet.
lint
A linter over the document, with the gutter and the diagnostics panel.
lsp_client
An editor talking to a language server: diagnostics, hover, completion, jump to definition.
search
The search panel, find and replace, and highlighting the selection's matches.
highlight
Underlining the selection: a state field of decorations updated by an effect.
widgets
Block widgets drawn in the document, keeping their place as the text above them changes.
compartment
Swapping parts of the configuration at run time: the line-number gutter and line wrapping.
gutter
A gutter of our own beside the line numbers, with markers from a range set.
tooltip
A hover tooltip showing what is under the pointer.
view_plugin
A view plugin maintaining decorations as the viewport moves.
panel
A panel below the editor, toggled by a key binding.
theme
Stacking themes: One Dark, with one of our own on top.
selection
Changing the document and the selection in one transaction.
collab
Two editors kept in sync through a collaboration authority.
headless
An editor state with no editor: transactions applied and read with no page at all.

Ported from codemirror.net

Every one of CodeMirror's own examples, translated as closely as OCaml allows, so the upstream page's code and prose read straight across. Each is upstream/<name>/, named as upstream names it; its selfcheck.ml is ours. Internet Explorer 11 is left out: it is about transpiling JavaScript for a browser js_of_ocaml does not target.
