# Code_mirror

The `codemirror` package: `basic_setup : Extension.t` and `minimal_setup
: Extension.t` from `__CM__codemirror`, plus `module State = Cm_state`,
`View = Cm_view`, `Language = Cm_language`, `Commands = Cm_commands`,
`Autocomplete = Cm_autocomplete`, `Lint = Cm_lint`, `Search = Cm_search`,
`Legacy_modes = Cm_legacy_modes`, `Theme_one_dark = Cm_theme_one_dark`.
An .mli with the same aliases and a preamble explaining that depending on
this library links every package, as the npm package does.
